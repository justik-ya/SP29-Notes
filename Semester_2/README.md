# Конспекты СП МКН за второй семестр первого курса

Затеханые конспекты по:

- [матану](./matan)
- [алгебре](./algebra)
- [дискре](./discretemath)
- [алгосам](./algorithms)

## Структура

Каждый предмет — отдельная папка. Внутри лежит основной `.tex`-файл, собранный `.pdf`
и папка `sections/` с материалом, разбитым по темам/билетам. Картинки — в `img/`.

## Сборка

Файлы собираются через `xelatex` (кодировка UTF-8). Вспомогательные файлы
сборки (`*.aux`, `*.log`, `*.synctex.gz` и т.п.) в репозиторий не коммитятся —
см. `.gitignore`.

## Правила

1. **В `main` напрямую не пушим.** Любые изменения — только через **Pull Request (PR)**.
2. **Один файл = одна тема/билет** в `sections/`. Это уменьшает конфликты при слиянии.
3. PDF помечены в `.gitattributes` как бинарные, чтобы git не пытался сливать их построчно.
