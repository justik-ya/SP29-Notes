# Профиль предмета — шаблон

Заводя новый предмет, скопируй этот файл в `subjects/<slug>.md` и заполни.
Профиль отвечает на вопрос «что в этом курсе устроено иначе», а не пересказывает
программу.

```markdown
# <Название предмета>

**Папка:** `Semestr_3/<slug>/`
**Лектор:** <фамилия И. О.>
**Цвет обложки:** `#XXXXXX`, линии узора `#XXXXXX`

## Обозначения
Принятые в курсе буквы и соглашения, которые лектор использует без пояснений.

## Макросы
Что положено в `meta.tex` и почему.

## Характер иллюстраций
Какие рисунки в этом курсе типичны — какие рецепты из кулинарной книги
понадобятся чаще всего.

## Особенности
Всё, обо что уже спотыкались: манера лектора, что он систематически не
дописывает, где нужен особенно аккуратный разбор.
```

## Цвета обложек

Цвет — единственный визуальный идентификатор курса на полке, поэтому оттенки
должны заметно отличаться. Все — тёмные и приглушённые, чтобы белый текст и
светлые линии узора читались.

| Предмет | Фон | Линии |
|---|---|---|
| Математический анализ | `#14212E` | `#8FC2E0` |
| Архитектура компьютера | `#221A1A` | `#E0A899` |
| Теоретическая информатика | `#1B1428` | `#C0A6E8` |
| Алгоритмы и структуры данных | `#14172E` | `#A9B4EE` |
| Базы данных | `#12241E` | `#93D4B4` |
| Программная инженерия | `#241E12` | `#E3C48D` |
| Функциональное программирование | `#101F24` | `#8ED2D6` |

Если курс не из списка — бери тёмный оттенок с той же светлотой и подбери линии
как ту же краску, осветлённую до пастели.

## Что менять в `meta.tex`

```latex
\newcommand{\subjectname}{Полное название}        % на обложку, в две строки влезает
\newcommand{\subjectshort}{Короткое название}     % в колонтитул, одна строка
\newcommand{\lecturer}{Фамилия И.\,О.}
\newcommand{\coursemeta}{СПбГУ \ $\cdot$ \ МКН \ $\cdot$ \ СП \ $\cdot$ \ 2 курс \ $\cdot$ \ осенний семестр}
\definecolor{subjcolor}{HTML}{......}
\definecolor{coverline}{HTML}{......}
```

Ниже — предметные макросы. Правило: макрос заводится, когда обозначение
встречается больше трёх раз или когда его легко набрать неверно.
